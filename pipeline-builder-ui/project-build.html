The folder must be an absolute path and empty or not yet created. The browser cannot browse server folders, so type the path where the backend runs.

Graal builds require GraalVM Native Image, Maven, and a supported native compiler toolchain on the backend machine. Micronaut web/UI projects include serve and embedded UI assets; Kafka native builds remain unsupported. Selected processing plugins may need native reachability metadata. Download the project ZIP and keep emitted DLL/shared-library files beside the executable; document/image parsers may need them.

Each populated ingestion or query workflow must be a connected linear plugin chain. Both workflows are packaged together; branching and fan-in within a workflow are not supported by this launcher format.
