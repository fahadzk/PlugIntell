# Icon provenance

The outline SVG paths in `studio.js` were authored for PlugIntell. They use familiar command shapes and a consistent Fluent-inspired outline style. They are not redistributed Microsoft system-icon assets, Apple artwork, an icon font, or a third-party icon package.

Icons are created inline by the local script and require no remote requests. Important actions retain visible labels; compact icon-only buttons have accessible names and tooltips. The interface uses system fonts rather than downloading proprietary or external fonts.

Design references: [Fluent layout](https://fluent2.microsoft.design/layout) and [Fluent iconography](https://fluent2.microsoft.design/iconography/).
