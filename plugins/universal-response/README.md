# Universal Response Renderer

Self-contained query output plugin with an embedded JDK HTTP server, bundled browser UI, format detection, safe renderers and temporary exports.

See the [complete setup, API contracts, architecture and verification guide](../../docs/plugins/universal-response.md).

After building the repository with Java 21, run `run-demo.bat --no-browser` on Windows or `sh run-demo.sh --no-browser` on Linux/macOS. Open http://127.0.0.1:8765/ and press Ctrl+C in the terminal to stop the demo. The dataset is illustrative and requires no model or database.
